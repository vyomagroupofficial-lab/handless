# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The Vyoma Handless team takes the security of our users and their desktop environments seriously.

If you discover a security vulnerability (such as unintended privilege escalation, arbitrary command execution, or credential exposure), please **do not disclose it publicly** via GitHub Issues.

Instead, please send an email to:
**security@vyoma.group** (or open a Private Vulnerability Advisory on GitHub).

Please include:
1. A clear description of the vulnerability.
2. Steps or a proof-of-concept script to reproduce the issue.
3. The potential impact of the issue.

We will acknowledge receipt within 48 hours and work with you to release a coordinated security patch.
