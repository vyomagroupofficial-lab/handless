Next-Gen Capabilities

Engineered For Pure Productivity

Every layer was designed from scratch to overcome traditional voice assistant lag and fragile coordinate clicking.

Wispr Flow Speculative Dictation

Streams discrete 200ms audio chunks in parallel background threads to Groq Whisper Large v3. Text slams onto the cursor in sub-100ms when you release the push-to-talk key.

True Web DOM Piercing

Automatically wakes Chromium's hidden accessibility engine and bridges with Chrome DevTools Protocol (CDP) on localhost:9222 to read raw web DOM nodes, attributes, and ARIA labels.

Zero-Lag UIA Chrome / Edge / Brave CDP Bridge

Install From Source

Clone the GitHub repository and run locally in an isolated virtual environment.

PowerShell 
git clone https://github.com/vyomagroupofficial-lab/handless.git
cd handless
python -m venv .venv
.\.venv\Scripts\activate
pip install -e ".[dev]"
python -m handless.app

No! Handless includes a 100% offline speech recognition engine (Sherpa-ONNX int8 Whisper Base) and local regex rules that operate entirely on your CPU without any internet connection. You can optionally add a free Groq API key (for cloud Whisper Large v3) and a free Google Gemini key (for Screen Lens & Gemini Live) directly in Settings.

While you hold F8, Handless buffers your live microphone stream into small 200ms audio frames. As soon as you finish a phrase, it pre-transcribes the audio in parallel background threads. When you release F8, the text is already transcribed, resulting in instantaneous sub-100ms text typing into your active application.

Handless has a hardware-level Emergency Stop built-in. Press Ctrl + Shift + Q (or tap Escape twice) at any time to instantly kill all in-flight mouse, keyboard, and window automation tasks.

Handless is currently exclusive to Windows 11 and Windows 10 (64-bit). It deeply hooks into native Windows OS subsystems including Windows UIAutomation (UIA COM), Core Audio Endpoint APIs, WMI display brightness controls, and Win32 window management hooks. Because these low-level APIs do not exist on Android or iOS, Handless cannot run on mobile devices. You can read all documentation and watch demos here on your phone, then download Handless on your Windows PC!
