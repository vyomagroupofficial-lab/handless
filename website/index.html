    Got questions?

    Frequently asked

    Does Handless need a paid API key?

    No. The installer bundles a fully offline speech engine (Sherpa-ONNX int8 Whisper Base) and local rules that run entirely on your CPU with no internet. You can optionally add a free Groq key (for cloud Whisper Large v3) and a free Google Gemini key (for Screen Lens and Gemini Live) in Settings.

    Can I run it on Android, iOS or Mac?

    Handless is Windows 11 / 10 (64-bit) only. It hooks deep into Windows subsystems — UI Automation (UIA COM), Core Audio endpoints, WMI brightness and Win32 window management — which don't exist on Android or iOS. Read the docs and try the demo here on your phone, then download on your Windows PC.

    How does speculative dictation work?

    While you hold Ctrl Shift, Handless buffers the mic stream into 200 ms frames and pre-transcribes finished phrases in parallel background threads. By the time you release the keys the text is already transcribed, so it's typed into your app in under 100 ms.

    How do I stop an accidental voice action?

    Press Ctrl Shift Q — or tap Esc twice — at any time. The emergency stop instantly kills all in-flight mouse, keyboard and window automation.

    Can I add my own voice workflows?

    Yes. Say “start macro recording” to record your own keystrokes and clicks into a voice macro. Developers can add patterns to LocalRuleParser or write native Python plugins.
